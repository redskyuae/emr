## 2026-07-23 - [HIGH] Missing Authentication on Master Data API Endpoints
**Vulnerability:** Global master data API endpoints (such as `app/api/v1/countries/route.ts`) lacked authentication checks entirely. They were presumably intended to be authenticated using standard helpers, but since they are not tenant-specific, `requireTenantSession()` was not used, and they were left fully unprotected.
**Learning:** This codebase uses route-level authentication via helpers (e.g., `requireAuth()`, `requireTenantSession()`) rather than Next.js global middleware. This pattern is prone to omission, especially on endpoints that don't need tenant isolation and therefore don't call the more heavily-used `requireTenantSession()`.
**Prevention:** Always verify that every exposed API route explicitly imports and calls either `requireAuth()`, `requireTenantSession()`, or `requireTenantAdminSession()`. Consider implementing a global middleware check for authenticated API paths to enforce security at the edge level and provide defense-in-depth against forgotten route-level checks.
