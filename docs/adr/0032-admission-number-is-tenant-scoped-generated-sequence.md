# Admission Number Is a Tenant-Scoped Generated Sequence

Every Admission receives a permanent, human-facing Admission Number generated by the system at admit time: the literal prefix `ADM-` followed by a Tenant-scoped integer sequence beginning at `1001`. The number is immutable and never reused, including after the Admission is soft deleted.

This mirrors ADR 0024 (Booking Number) and ADR 0028 (Visit Number) exactly, for the same reasons: ward staff and patients need a short, quotable identifier that is not the database id; per-tenant sequences avoid leaking cross-tenant volume; and starting at `1001` keeps early numbers from looking like test data.

Generation uses the same mechanism as the Visit Number: a dedicated `admission_number_counter` table keyed by `tenant_id`, incremented inside the admit transaction with an insert-or-update, so two concurrent admissions can never draw the same number. A unique index on `(tenant_id, lower(admission_number))` is the backstop.
